## Installation

You need node version 18.13.0 or higher...

Install TVP App with npm or yarn

In the root of the project run : 

Npm :
```bash
  npm install
```

Yarn :
```bash
  yarn install
```

Then go to

```bash
  cd .\tvpMobile\
```
    
And then, to run the project, run :

```bash
npx expo start
```
